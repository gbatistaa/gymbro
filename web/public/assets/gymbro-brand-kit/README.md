# GYMBRO — Brand kit

## Direção selecionada
Símbolo geométrico inspirado em uma barra de peso: placas simétricas conectadas por uma barra central. A construção evita detalhes finos desnecessários e mantém uma silhueta reconhecível em tamanhos reduzidos.

## Paleta
- Background: `#0B0D0C`
- Surface: `#141816`
- Primary text: `#F2F5F3`
- Secondary text: `#8A958F`
- Brand green: `#3DDC6E`

## Arquivos
- `svg/01-horizontal-primary-dark.svg`: símbolo verde + wordmark branco, fundo escuro.
- `svg/02-horizontal-white-dark.svg`: versão horizontal branca, fundo escuro.
- `svg/03-stacked-dark.svg`: versão vertical para login/splash.
- `svg/04-app-icon-1024.svg`: ícone quadrado com cantos arredondados, 1024 × 1024.
- `svg/05-monochrome-white-transparent.svg`: logo branco monocromático com fundo transparente.
- `svg/06-monochrome-black-white.svg`: símbolo preto sobre branco.
- `svg/07-favicon-24.svg`: símbolo simplificado para 24 px.
- `svg/08-maskable-1024.svg`: PWA maskable, fundo em full bleed e símbolo dentro da área segura.
- `svg/09-symbol-thick.svg` e `svg/10-symbol-thin.svg`: variações do símbolo.
- `svg/concept-02-progression.svg` e `svg/concept-03-geometric-g.svg`: conceitos alternativos.
- `svg/00-concept-comparison-board.svg`: prancha comparativa editável.

Os SVGs são vetoriais e editáveis. O wordmark usa uma pilha de fontes sem serifa (`Inter`, `Arial`, `Helvetica`, `sans-serif`); para consistência absoluta entre ambientes, converta o texto em contornos no Figma/Illustrator antes da entrega final.
